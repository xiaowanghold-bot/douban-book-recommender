## 1. 基础数据清洗 (data_cleaning.py: clean_basic)

| # | 规则 | 动机 | 实现 | 案例 |
|---|------|------|------|------|
| 1.1 | 去除无评分/评价数记录 | 评分=0 或 votes=0 的书无推荐价值 | `df[(df["rating"]>0)&(df["votes"]>0)]` | 288,824 → ~280K |
| 1.2 | 去除缺失书名 | 无名书籍无法展示和搜索 | `df[df["title"].notna()&(df["title"]!="")]` | 过滤空书名行 |
| 1.3 | 评分范围检查 | 豆瓣评分合法范围 2-10 | `df[(df["rating"]>=2)&(df["rating"]<=10)]` | 排除异常值（如 0 分、99 分） |
| 1.4 | 去重（同一ID） | 部分书籍因多次爬取存在重复行 | `df.drop_duplicates(subset=["id"], keep="first")` | 保留首次出现的记录 |
| 1.5 | 类型转换 | 统一 id→int, rating→float, votes→int | `astype(int/float)` | 确保后续计算正确 |

## 2. 爬虫详细数据清洗 (data_cleaning.py: clean_detail)

| # | 规则 | 动机 | 实现（正则/逻辑） | 前后案例 |
|---|------|------|------|------|
| 2.1 | 仅保留爬取成功记录 | 爬虫失败的记录字段为空 | `detail[detail["crawl_status"]=="success"]` | 6,584 → 6,575 (9本失败) |
| 2.2 | 价格解析 | "29.00元" 无法直接计算 | `re.search(r"(\d+\.?\d*)", str(val))` | "29.00元" → 29.0 |
| 2.3 | 页数解析 | "191页" 需提取数字 | `re.search(r"(\d+)", str(val))` | "191页" → 191 |
| 2.4 | 出版年解析 | "2006-5" 只需年份 | `re.search(r"(\d{4})", str(val))` | "2006-5" → 2006 |
| 2.5 | ISBN 清理 | 含连接符/空格影响匹配 | `re.sub(r"[^\dXx]", "", str(val))` | "978-7-5321-..." → "97875321..." |
| 2.6 | 装帧分类 | "平装"/"精装"二分类 | `"精装" in text → "精装" else "平装"` | "平装"/"精装" 为主，其他保留原文 |
| 2.7 | 作者国籍提取 | "[日] 东野圭吾" 标注翻译作品 | `re.search(r"\[(.+?)\]", text)` + 映射表 | "[日]" → "日本"；无标注 → "中国" |

## 3. 名称归一化 (normalize.py)

### 3.1 出版社归一化 (normalize_publisher, 约 50 行)

| 步骤 | 规则 | 案例 |
|------|------|------|
| 拆分合并条目 | "A出版社 / B出版社" → 取第一个长度>=4的部分 | "人民文学出版社 / 作家出版社" → "人民文学出版社" |
| 繁简转换 | 常见繁体出版社名 → 简体 | "東立" → "东立" |
| 后缀剥离 | 移除 "有限公司"/"股份有限公司" 后缀 | "东立出版社有限公司" → "东立出版社" |
| 映射表匹配 | 30+ 变体 → 规范名 | "三联书店" → "生活·读书·新知三联书店"；"皇冠" → "皇冠文化出版有限公司" |

### 3.2 作者归一化 (normalize_author, 约 15 行)

| 步骤 | 规则 | 案例 |
|------|------|------|
| 去除国籍标注 | `[...]` 括号内容移除 | "[日] 东野圭吾" → "东野圭吾" |
| 合著拆分 | "/" 分隔取第一作者 | "作者A / 作者B" → "作者A" |
| 繁简映射 | 常见变体 → 正体 | "钱钟书" → "钱锺书" |

## 4. 多版本去重 (utils.py: dedup_editions)

| 步骤 | 规则 | 案例 |
|------|------|------|
| 版本括号去除 | 仅移除含“第X版/修订版/精装/套装”等明确版本标记的括号内容 | "深入理解计算机系统（原书第3版）" → "深入理解计算机系统" |
| 全角符号去除 | 中文标点（，。！？《》等） | 清除书名中用于装饰的标点 |
| 卷册边界保留 | “卷Ⅱ/卷Ⅲ、上/下册、卷1/卷2”等内容标记不参与版本折叠 | “三体Ⅱ”与“三体Ⅲ”分别保留 |
| 按 votes 去重 | 归一化后同书名保留评价人数最高版 | 两版"深入理解计算机系统" 留 votes 更高的 |
